Android-Client

Deine RetroHub-Spielhalle für die Hosentasche.

Die Spiele deines RetroHub-Servers, offline spielbar, mit Spielständen, die dir ins Web folgen.

APK herunterladen Der RetroHub-Server

Ein Client für den RetroHub-Server

Die App funktioniert nicht allein: Sie verbindet sich mit deinem selbst gehosteten RetroHub-Server. Bibliothek, Spiele, Spielstände und Spielzeit kommen von dort.

RetroHub entdecken Quellcode des Servers

Funktionen

Offline

Ein heruntergeladenes Spiel läuft ohne Netz. Alles wird synchronisiert, sobald die Verbindung zurück ist.

Ein Spielstand, überall

Auf dem Handy beginnen, im Browser weiterspielen – und umgekehrt.

Nichts wird überschrieben

Zwei Versionen desselben Spielstands? Du wählst, welche bleibt.

Wie eine Konsole

Steuerung per Controller, Touch oder Tastatur.

Originalgetreue Steuerung

Ein Touch-Layout pro Konsole, frei verschiebbar, ausgeblendet, sobald ein Controller verbunden ist.

Einstellungen pro Konsole

Emulator, Darstellung, Sprache, Region, Tasten, Dauerfeuer und Cheatcodes.

Installieren

  1. Lade die neueste Version der APK herunter und installiere sie.
  2. Gib die Adresse deines RetroHub-Servers ein.
  3. Verbinde das Handy mit dem im Web angezeigten Code oder mit deinem Passwort.

Code unter MIT-Lizenz. Die APK enthält LibretroDroid und libretro-Cores unter ihren eigenen Lizenzen.
