Your RetroHub arcade, in your pocket.

The games of your RetroHub server, playable offline, with saves that follow you to the web.

A client for the RetroHub server

The app does not work on its own: it connects to your self-hosted RetroHub server. The library, games, saves and play time come from it.

Discover RetroHub Server source code

Features

Offline

A downloaded game plays without a network. Everything syncs when the connection is back.

One game, everywhere

Start on the phone, continue in the browser, and the other way round.

Nothing overwritten

Two versions of the same save? You choose which one to keep.

Like a console

Navigate with a controller, by touch or with a keyboard.

Faithful controls

A touch layout for each console, movable by hand, hidden as soon as a controller connects.

Per-console settings

Emulator, rendering, language, region, buttons, turbo and cheat codes.

Screenshots show the app in French. More app languages are coming.

Install

  1. Download the latest version of the APK and install it.
  2. Enter the address of your RetroHub server.
  3. Link the phone with the code shown on the web, or with your password.
